Create a clean and production-ready MVP URL shortener web application using Django and Django REST Framework.

Project goal:
Build a simple but modern URL shortener SaaS MVP with:

* custom short links
* QR code generation
* click tracking
* simple dashboard
* authentication
* responsive frontend

Important:
This is an MVP project.
Do NOT overengineer the architecture.
Avoid unnecessary enterprise complexity.

Tech stack:

* Django 5+
* Django REST Framework
* SQLite (Aiosqlite)
* Django Templates
* HTML + CSS + minimal JavaScript
* Bootstrap or TailwindCSS
* JWT authentication
* Google OAuth login
* Gunicorn
* Environment-based settings

DO NOT USE:

* Docker
* Redis
* Celery
* Kubernetes
* Microservices
* Complex frontend frameworks
* React or Next.js

1. Shorten long URLs
2. Custom aliases
3. QR code generation
4. URL redirect handling
